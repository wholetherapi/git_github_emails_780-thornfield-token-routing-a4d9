# Adaptive Token Routing for Sparse Mixture-of-Experts

**Released** — code and model checkpoints are publicly available.

This repository contains the implementation and experimental code for the paper "Adaptive Token Routing for Sparse Mixture-of-Experts".

- `src/` — model and training code
- `data/` — dataset preparation scripts
- `experiments/` — experiment configuration
- `notebooks/` — analysis notebooks
- `results/` — reported metrics
- `tests/` — smoke tests
